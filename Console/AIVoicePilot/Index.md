**Edition:** Community · **Accuracy:** Shipped

**AI Voice Pilot** is a Community module for **spoken** Q&A against your project knowledge base: you speak, the system retrieves grounded answers, and replies are spoken aloud in a natural voice. No license key or entitlement is required.

It is **not** [Voice](/Console/Voice/Index) (browser STT/TTS mic and speaker controls on AI Chatbot and AI Search widgets). It is **not** [Admin Assistant](/Console/AdminAssistant/Index) or [AI Chatbot](/Console/AIChatbot/Index).

## What you get

- Dashboard **AI Voice Pilot** workspace with **Pilot**, **Voices**, and **Settings** tabs.
- Voice↔voice RAG against the active project’s sources.
- Optional Voice Pilot surface on chatbot **Layout 2** (Home CTA and footer tab).

## Voice providers

| Provider | Setup |
|----------|-------|
| **Custom** | Free neural voices from the server catalog — no API key. Browse and filter voices by language and gender on the **Voices** tab, and tune rate, pitch, and volume per voice. |
| **ElevenLabs** | Premium voices — add your ElevenLabs API key in **Settings**, then select a voice. |

Settings for each provider are stored separately, so you can switch providers without losing configuration.

## Permissions

With Enterprise organization RBAC, project access can include Voice Pilot **use** and **settings** permissions. Operators without those permissions cannot configure or run Pilot for that project.
