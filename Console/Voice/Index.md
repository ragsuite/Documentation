**Edition:** Community · **Accuracy:** Shipped

**Voice** adds browser speech-to-text and text-to-speech controls (mic / speaker) on **AI Chatbot** and **AI Search** widgets. It is a Community module — no license key or entitlement is required.

This is **not** [AI Voice Pilot](/Console/AIVoicePilot/Index) (dashboard speak-and-hear RAG with its own voice providers). Keep the two modules separate when configuring projects.

## Widget options

| Widget | Options |
|--------|---------|
| **AI Chatbot** | **Talk and listen** — visitors can speak into the chat (**Speak**) and hear answers read aloud (**Listen**) |
| **AI Search** | **Speech** — microphone control for speech input in the search box and a speaker control to read answers aloud |

Turn the options on per widget in the console widget customization, then test the embed in a browser that allows microphone access.
