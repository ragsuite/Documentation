**Edition:** Community

Projects isolate knowledge and configuration so teams can run multiple RAG contexts on one deployment (for example separate clients, departments, or corpora).

Community Edition product terms include **unlimited projects** (and unlimited users). Enterprise adds organization-level RBAC and membership controls — see [Organization & RBAC](/Enterprise/OrganizationAndRBAC/Index).

## Practical tips

- Keep high-trust corpora in dedicated projects.
- Align widget embeds and API keys with the project they should query.
- Prefer clear naming so audit and support can identify which project produced an answer.
