Security buyers and operators should be able to **check** claims, not take them on faith. RAGSuite is built so data stays in your perimeter, answers cite sources, and the Community Edition code you run is public under Apache 2.0.

**What this section covers**

- Sovereignty principles — self-host, air-gap, no phoning home.
- How to report issues and what the security policy expects.
- License and NOTICE scope for Community vs Enterprise.

Use these pages in due diligence alongside your own network and deployment review.
