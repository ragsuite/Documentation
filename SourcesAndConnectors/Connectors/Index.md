**Edition:** Community

**Connectors** pull knowledge **into** a project from the systems your team already uses. They are inbound Sources integrations — not the Management **MCP** screen that issues keys for external AI apps.

## Shipped inbound connectors

| Connector | Role |
|-----------|------|
| **Gmail** | Index mail into the project corpus |
| **Google Drive** | Index folders and files for search and chat |
| **Slack** | Index channel messages and files |
| **Microsoft Teams** | Index Teams content (Sources connector — not organization Team Members RBAC) |
| **Marketplace** | Connector marketplace surface for additional integrations |

**n8n** is **Beta** — see [n8n](/SourcesAndConnectors/N8n/Index).

Configure connectors in the console for the active project. Prefer authoritative sources your organization owns or is licensed to use, then verify citations after large syncs.

## Not MCP

To connect Cursor, Claude, VS Code, and similar hosts **to** RAGSuite with an MCP key and setup snippet, use [MCP](/SourcesAndConnectors/MCP/Index) (Management → MCP).
